# Agri Tourism Ecosystem Platform

เอกสารอธิบายระบบแพลตฟอร์มสมาชิก ทรัพยากร มาตรฐาน และการบริหารการขายของเครือข่ายเกษตรและการท่องเที่ยวในรูปแบบ HTML หน้าเดียว

## ระบบนี้อธิบายอะไร

- เป้าหมายและปัญหาที่แพลตฟอร์มต้องแก้
- บทบาทของสมาชิก ผู้ผลิต ผู้ประกอบการ และผู้ประสานงานเครือข่ายประจำพื้นที่
- รูปแบบการเก็บข้อมูลและความสัมพันธ์ของข้อมูล
- การติดตามมาตรฐานสินค้าและบริการ
- การเชื่อมโยงธุรกิจภายในเครือข่าย
- คลังสินค้า คำสั่งซื้อ การแจ้งเตือน การชำระเงิน และการจัดส่ง
- Workflow ตั้งแต่รับสมาชิกจนถึงปิดคำสั่งซื้อ
- Dashboard ตัวชี้วัด และแผนพัฒนาระบบเป็นระยะ

## วิธีเปิดดู

เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ ภาพประกอบที่หน้าเว็บใช้งานอยู่ใน `assets/illustrations/`

หน้าเว็บออกแบบให้รองรับทั้งเดสก์ท็อป มือถือ และการพิมพ์เป็นเอกสาร

## ภาพประกอบ

ภาพประกอบทั้ง 10 ภาพสร้างด้วยโมเดล Image Generate และบีบอัดเป็น WebP สำหรับใช้งานบนเว็บ ชุดคำสั่งที่ใช้สร้างภาพเก็บไว้ใน `assets/illustrations/PROMPTS.md`

ภาพเหล่านี้ใช้สื่อสารแนวคิดและ Workflow ของระบบ ไม่ใช่ภาพหน้าจอของซอฟต์แวร์ที่พัฒนาเสร็จแล้ว
